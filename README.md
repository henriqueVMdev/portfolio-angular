# Tétradrachma Digital (Angular)

Portfólio em Angular 21, refeito por etapas a partir do Next.js.

```bash
npm start
```

Abre em `http://localhost:4200`.

## Etapas para conferir

1. **Hero** — vídeo, partículas, nome e navegação (mobile: menu tela cheia).
2. **Home · projetos** — quatro estratos: Myrias, Basanos, OmniSeg, Kairós.
3. **Planta Myrias** — `/projetos/myrias` (visão, arquitetura Mermaid, OAuth, decisões).
4. **Planta Basanos** — `/projetos/basanos` (disciplina, funil, arquitetura, limites).
5. **Planta OmniSeg** — `/projetos/omniseg` (regras, ciclo SVG, camadas, limites).
6. **Método** — três princípios + órbita.
7. **Trajetória** — constelação (no mobile vira lista).
8. **Contato** — formulário, links, currículo PDF.

Responsividade reusa os breakpoints do original: 1100 / 900 / 767 / 680.
