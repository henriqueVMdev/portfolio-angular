# Tétradrachma Digital (Angular)

Portfólio em Angular 21, refeito por etapas a partir do Next.js.

```bash
npm start
```

Abre em `http://localhost:4200`.

1. **Hero** — nesta agora. Confira vídeo, partículas, nome e navegação.
2. Projetos — um estrato de cada vez
3. Método

5. Contato, PDF e API
